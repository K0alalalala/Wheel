Installing Wheel
================

1. Drag Wheel into Applications.
2. Open Wheel from Applications. A ◎ icon appears in the menu bar.

Wheel is free and not notarized by Apple, so the first launch is blocked:

  • macOS 15 or later: open System Settings → Privacy & Security, scroll down,
    and click "Open Anyway" next to the message about Wheel. Confirm once.
  • macOS 14: right-click Wheel in Applications, choose Open, then Open.

You only need to do this once. Wheel makes no network connections and
collects nothing. The source code is public, so you can build it yourself.

Using it: start dragging any file, hold Shift, drop it on a slice.

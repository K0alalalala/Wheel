# Contributing

Thanks for helping. Everything you need, for humans and coding agents alike, is in [AGENTS.md](AGENTS.md): commands, layout, how to add a format or tool, and the rules.

Short version:

1. `make check` must pass.
2. Never touch input files; write new ones beside them.
3. No network calls or telemetry.
4. Leave the credits alone. CI enforces it.
